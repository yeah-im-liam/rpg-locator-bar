# RPG Locator Bar

Makes the locator bar separate from the XP bar and High up like popular RPG's!

The mod separates the locator bar from the XP bar and moves it higher on the screen, similar to popular RPG-style HUDs. It is client-side only.

## Features

- Separates the locator bar from the XP bar
- Adjustable vertical positioning for the locator bar
- Optional XP bar visibility while the locator is active
- RPG-style HUD behavior without replacing vanilla mechanics
- The jump bar stays visible for the whole ride on horses and other jumpable mounts

## Configuration

Open the settings from Mod Menu (Fabric), the mod list's config button (NeoForge), or the "RPG Locator Bar Config Menu" key in Controls (unbound by default).

| Setting | Default | Description |
| --- | --- | --- |
| Vertical offset | 0 | Adjusts how high the locator bar appears on the screen. |
| Render XP overlay with locator | On | Keeps the XP bar visible while the locator is shown. |
| Hide XP bar in creative | On | Hides the XP bar in Creative, matching vanilla. |
| Keep locator during XP | On | Keeps the locator visible while XP is gained. |
| Locator bar always on | Off | Shows the locator bar even when there are no active targets. |

The Default Settings button resets everything to these values.

## Compatibility

- Minecraft: Java Edition 1.21.6 to 1.21.11 (one file per version)
- Loaders: Fabric (requires Fabric API, Mod Menu optional) and NeoForge
- Environment: client
